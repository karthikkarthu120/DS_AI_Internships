# Customer Analytics EDA Mini Project

## Overview
This project performs Exploratory Data Analysis (EDA) on a customer analytics dataset to understand purchasing behavior and demographic patterns.

## Project Workflow
1. Data Inspection
2. Data Cleaning
3. Univariate Analysis
4. Bivariate Analysis
5. Correlation Analysis
6. Insight Generation

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## How to Run

Install dependencies:

pip install -r requirements.txt

Run notebook:

jupyter notebook notebooks/MiniProject1_EDA.ipynb

## Key Insights
- Customer spending varies independently of income.
- Middle-aged customers form the majority group.
- Clean data significantly improves analysis reliability.
